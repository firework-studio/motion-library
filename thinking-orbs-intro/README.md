# Thinking Orbs Intro

A 40-second voiced intro to Thinking Orbs, an open-source set of dotted loading orbs by Jakub Antalik, picked by Firework Studio. A single orb switches state on every spoken word and folds into a triangle on "open source", then splits into a ring of nine that settles into a turning 3×3 grid. A picker swaps generic spinners for orbs inside chat, search and upload panels, one pill moves through six kinds of app from dark to light, a frame-rate line holds at 60 fps until a reduced-motion switch freezes every orb, the MIT licence types itself out, a Ship button gets pressed, and the film ends on the repo card. Word-by-word captions follow the voiceover throughout.

## Run

```bash
npm run dev       # Preview in the browser
npm run render    # Render to MP4
```

The orbs are drawn by the component's own engine, bundled unmodified into `assets/lib/thinking-orbs-engine.js`; `assets/lib/orb-view.js` drives it from timeline time so every frame can be seeked and rendered.
