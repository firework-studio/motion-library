# Creative Canvas Promo

A 13-second launch teaser: a rolling subscription counter surrounded by floating tool icons, kinetic type, a prompt typed into an app window, and a wordmark end card, linked by whip transitions.

## Preview

[Watch preview.mp4](https://github.com/firework-studio/motion-library/releases/download/creative-canvas-promo/preview.mp4) · 1920×1080 · 13.2 s

## Reference

Shots, motion and pacing follow the [Kyoso launch video](https://x.com/kyoso_ai/status/2096917096722510159) by [@kyoso_ai](https://x.com/kyoso_ai). Copy and branding are replaced with Firework Studio's own.

## Run

```bash
npm run dev       # Preview in the browser
npm run render    # Render to MP4
```
