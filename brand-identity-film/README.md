# Brand Identity Film

A 69-second identity film for Tilo, a concept brand for makers, built from one shape: a square tile with one rounded corner. Tiles flatten from 3D cubes into the wordmark, whose dotless ı takes a copper tile for its dot. A pixel font decodes the slogan, the symbol docks against the lettering, and product names scroll through a detent. The alphabet, stylistic alternates and a stroke-built @ and & pull back into a wall of characters, followed by five weights of Tilo Sans and Tilo Mono. Colour blocks spiral in, turn in a ring and fold into one tile. Photos give way to sorted stripes, brass lines, a dancer drawn in dashes and a dithered heron. Then come nested windows with a glossy sticker, a wall of animated icons, live app screens, and the brand on posters, a subway car, a billboard and merch. A rewind recap and a liquid morph from modules to letters lead to a spiral fold, and the film ends on the Firework Studio signature.

## Run

```bash
npm run dev       # Preview in the browser
npm run render    # Render to MP4
```

Most scenes draw on a canvas from timeline time, so every frame can be seeked and rendered. Render with `--workers 1` to keep static type perfectly still.
