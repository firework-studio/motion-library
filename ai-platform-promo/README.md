# AI Platform Promo

A 31-second brand film that moves from overload to order. Dark kinetic type and branching signal lines resolve into a ring the camera flies through; the studio name types out; a prompt sends a vortex of poster cards spinning; code fails, glows red and repairs itself beside a voxel cube; scattered labels grow into a paper-cut tree that blossoms; a rotating tagline lands on the logo.

## Preview

[Watch preview.mp4](https://github.com/firework-studio/motion-library/releases/download/ai-platform-promo/preview.mp4) · 1920×1080 · 31.1 s

## Run

```bash
npm run dev       # Preview in the browser
npm run render    # Render to MP4
```
